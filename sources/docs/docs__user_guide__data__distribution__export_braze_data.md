# Exporting Braze Data 

Braze provides CSV exports of Braze dashboard data, allowing you to analyze the data with a variety of tools. The following articles cover the different types of data you can export from the dashboard, as well as tips for opening the data in Excel and performing exports with our API.

Before performing your export, make sure you have selected the right time frame that you want to view data from.
