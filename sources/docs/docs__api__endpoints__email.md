# Email Lists & Addresses Endpoints 

Using this set of endpoints, you can update a user’s email subscription status, and use the Braze API to set up bi-directional sync between Braze and other email systems or your own database.

## 

- 

 GET: List Hard Bounces

- 

 GET: Query Unsubscribed Email Addresses

- 

 POST: Change Email Subscription Status

- 

 POST: Remove Hard Bounces

- 

 POST: Remove Spam

- 

 POST: Blocklist Email
