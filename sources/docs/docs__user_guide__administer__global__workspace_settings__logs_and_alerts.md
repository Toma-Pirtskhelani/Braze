# Logs and alerts 

Braze provides several logging and alerting tools to help you monitor what’s happening across your workspace. 

Set up API usage alerts to track call volumes and get notified when usage approaches your rate limits. Use the event user log to look up individual user events when troubleshooting integration issues or debugging campaign behavior. Check the exports log to see the status of segment and campaign data exports, and review the message activity log for details about message delivery, including send attempts, confirmations, and errors.
