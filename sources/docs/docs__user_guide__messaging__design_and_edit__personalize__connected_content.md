# Connected Content 

Braze Connected Content expands on marketing personalization to boost customer engagement and conversions. This feature allows you to insert any information accessible via API directly into messages you send to users. Connected Content allows for pulling content either directly from your web server or from publicly accessible APIs. You can also use our Connected Content capabilities with our Technology Partners, like AccuWeather and Transifex.

In addition to the following articles listed, we recommend checking out our Connected Content Braze Learning course.
