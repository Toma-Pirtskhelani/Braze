# Figma

Figma is a collaborative design platform that allows you to build, design, and prototype products.

## About the integration

The Braze and Figma integration allows you to send images and visual assets from Figma directly into the Braze media library.

Watch this video for an overview of how the integration works.

## Prerequisites

 Requirement | 
 Description | 

 Figma account | 
 A Figma account is required to take advantage of this partnership. | 

 Braze media library access | 
 You must have “Manage Media Library Assets” permission to add, edit, and delete media library assets in Braze. | 

 Braze workspace access | 
 You must have access to the workspaces you want upload these Figma images and visual assets to in Braze. | 

## Integration

### Step 1: Install the Figma to Braze Export plugin

Go to Figma’s Community to access the Braze Export plugin. Select Open In to load the plugin into your Figma file.

In Figma, you can also find the Figma to Braze Export plugin in the Plugins section.

### Step 2: Connect to Braze

After installing, select Connect to Braze to connect your Braze account, then select Continue.

Next, select your Braze workspace from the Braze workspace dropdown or enter the workspace name.

### Step 3: Select your Figma assets

Select the images and visual assets to export to Braze. To select multiple assets, you can press Shift or drag and drop your cursor over the assets.

The name of the exported image or visual asset uses the name of the selected frame in Figma.

### Step 4: Export to Braze

Select Export to Braze. Your images and visual assets are uploaded into the Braze media library. All images imported using this integration have their source set to Figma.
