# Keyword processing 

Keywords are a foundational aspect of automated SMS, MMS, and RCS messaging. With keywords, your users can message a preset list of single-word commands that do some action, such as opting in and out of receiving SMS, MMS, or RCS messages. With Braze, you can also set custom keywords and turn on fuzzy opt-out to further tailor your user journey. 

 These articles cover how Braze approaches keyword processing and management and some best practices.
