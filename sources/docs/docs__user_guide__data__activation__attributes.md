# Attributes 

Attributes store information about your users on their user profiles.

Standard attributes (like first name, email, country, and language) are predefined fields you can set through the Braze SDK or the User Attributes API. Custom attributes are flexible, brand-specific fields you define to capture traits unique to your business, such as subscription tier or favorite category. 

Together, attributes power segmentation, personalization, and analytics across your campaigns and Canvases.
