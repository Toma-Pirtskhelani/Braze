# API and SDK endpoints

Look up the correct dashboard URL, REST API endpoint, and SDK endpoint for your Braze instance. You need these URLs to log in, make API calls, and integrate the SDK.

Braze manages a number of different instances for our dashboard, SDK, and REST endpoints, which we call “clusters.” Your Braze onboarding manager will let you know which cluster you’re on. To learn more about the Braze SDK, check out the Braze 101 Braze Learning course.

Logging in at dashboard.braze.com automatically sends you to the correct cluster address.
