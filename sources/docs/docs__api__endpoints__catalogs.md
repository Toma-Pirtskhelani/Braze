# Catalogs Endpoints 

Use the Braze Catalogs Endpoints to add, edit, and manage your catalogs and catalog item details. For bulk changes to your catalog, use the asynchronous catalog endpoints. 

 Looking for guidance on creating a catalog? Check out our article for creating and using catalogs.

## Catalog management endpoints 

- 

 DELETE: Delete Catalog

- 

 GET: List Catalogs

- 

 POST: Create Catalog

## Asynchronous catalog items endpoints 

- 

 DELETE: Delete Multiple Catalog Items Endpoints

- 

 PATCH: Edit Multiple Catalog Items

- 

 POST: Create Multiple Catalog Items

- 

 PUT: Update Multiple Catalog Items

## Synchronous catalog items endpoints 

- 

 DELETE: Delete Catalog Item

- 

 GET: List Catalog Item Details

- 

 GET: List Multiple Catalog Item Details

- 

 PATCH: Edit Catalog Item

- 

 POST: Create Catalog Item

- 

 PUT: Replace Catalog Item

## Asynchronous catalog fields endpoints 

- 

 POST: Create Catalog Fields

- 

 DELETE: Delete Catalog Field

## Asynchronous catalog selections endpoints 

- 

 POST: Create Catalog Selections

- 

 DELETE: Delete Catalog Selection
