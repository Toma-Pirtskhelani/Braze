# Workspace settings 

Workspace settings apply only to the workspace you’re currently viewing. Use these settings to manage API keys, configure email and push preferences, set up brand guidelines, and monitor workspace activity through logs and alerts.

Most features within Workspace Settings are only available to Braze account administrators. If you don’t have access but feel that you should, contact your company’s Braze account administrator. Company-wide OAuth policy, including MCP access, is configured in Admin settings.
