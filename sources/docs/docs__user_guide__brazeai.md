# BrazeAITM 

BrazeAITM powers a collection of accessible, easy-to-use tools that lower the barriers to entry for creativity, personalization, and optimization for your engagement strategy. With BrazeAITM capabilities, you can have a trusted advisor to help guide your creativity, make better decisions, and optimize the user experience for your customers. This hub links to guides for generative AI, the Intelligence Suite, item recommendations, agents, and other BrazeAI features you can use in campaigns and Canvases.
