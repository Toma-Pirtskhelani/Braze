# Braze Developer Guide 

This is where developers find everything they need to integrate the Braze SDK and related APIs. Each SDK is hosted in its own public GitHub repository with fully buildable sample apps you can use to test Braze features or implement alongside your own applications. Browse platform guides for Web, iOS, Android, and other integrations, then refer to References, Repositories, and Sample Apps for repository links. Want to connect with other developers building on Braze? Join the Braze developer community!
