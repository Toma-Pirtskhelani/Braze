# SDK Authentication Endpoints 

Use these endpoints to create and manage SDK Authentication keys for your app. SDK Authentication keys allow you to securely authenticate your mobile SDK instances with Braze.

## 

- 

 POST: Create SDK Authentication Key

- 

 GET: List SDK Authentication Keys

- 

 PUT: Set Primary SDK Authentication Key

- 

 DELETE: Remove SDK Authentication Key
