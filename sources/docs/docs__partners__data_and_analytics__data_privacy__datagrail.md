# DataGrail

DataGrail, a privacy management platform, helps build consumer trust and eliminate risky business. With continuous system detection and automated data subject request (DSR) fulfillment, DataGrail powers privacy programs, supporting compliance with evolving privacy laws and regulations, like GDPR, CCPA, and CPRA.

This integration is maintained by DataGrail.

## About the integration

The Braze and DataGrail integration allows you to detect consumer data collected and stored within Braze to quickly process DSRs (access, delete, and do-not-sell requests). Braze will be added to an accurate blueprint of where consumer data lives in your organization with automated data mapping — no more surveys or spreadsheets are needed to maintain a privacy framework or produce a record of processing activities (RoPA).

 DataGrail account |

 Braze API key | 
 A Braze REST API key with events.list, users.export.ids, users.delete, and users.track permissions.

This can be created in the Braze dashboard from Settings > API Keys. | 

 Braze instance | 
 Your Braze instance can be obtained from your Braze onboarding manager or can be found on the API overview page. | 

## Integration

Login to the DataGrail portal and select Connect within the integration page for Braze. Next, enter your instance and Braze API Key and select Connect Braze.

If there are additional Braze accounts to integrate:

- Select Edit Connection within the integration page for Braze.
 
- From the dropdown, select +Add New Connection.
 
- Under Connection Name, enter a new name to identify this separate account (for example, Braze Training Account).
 
- Enter a separate Braze instance and API key for this new account.
 
- Select Connect.

Email DataGrail at [email protected] with any issues or questions regarding your integration.
