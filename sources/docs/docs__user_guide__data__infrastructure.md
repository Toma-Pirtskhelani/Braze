# Data infrastructure 

Data infrastructure at Braze includes data centers that help to minimize latency, which is the time it takes for data to travel between the server and the user. This allows our services to be reliable and scalable. This also includes field-level encryption to help protect sensitive data to minimize personally identifiable information (PII) shared in Braze.
