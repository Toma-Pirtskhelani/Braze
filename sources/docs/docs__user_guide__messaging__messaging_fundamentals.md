# Fundamentals 

Set who receives your message, when it sends, and how you measure success—whether you use a campaign or a Canvas. This section covers audience targeting, delivery and entry types, conversion event tracking, frequency capping, re-eligibility rules, localization, accessibility, and the pre-launch checklist. Review these concepts before building so your messages reach the right users without overwhelming them.
