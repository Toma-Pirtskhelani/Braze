# Subscription Groups Endpoints 

Use the Subscription Group REST APIs to programmatically manage the subscription groups stored in your Braze workspace. This applies to email and SMS subscription groups.

 For dashboard guidance on creating and managing groups, see Subscription groups.

## 

- 

 GET: List User's Subscription Group Status

- 

 GET: List User's Subscription Groups

- 

 POST: Update User's Subscription Group Status

- 

 POST: Update User's Subscription Group Status V2
