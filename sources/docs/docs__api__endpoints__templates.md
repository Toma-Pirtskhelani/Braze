# Templates Endpoints 

Using the Template endpoints, you can create and manage your templates for email and Content Blocks. 

 Looking for more guidance on creating templates for email and Content Blocks? Check out our dedicated for Email Templates section and Content Blocks article.

## Email template endpoints 

- 

 GET: List Available Email Templates

- 

 GET: See Email Templates Information

- 

 POST: Create Email Template

- 

 POST: Update Email Template

## Content Block template endpoints

- 

 GET: List Available Content Blocks

- 

 GET: See Available Content Block Information

- 

 POST: Create Content Blocks

- 

 POST: Update Content Block
