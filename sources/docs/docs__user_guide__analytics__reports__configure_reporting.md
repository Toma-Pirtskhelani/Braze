# Configure reporting

Braze automatically generates a weekly email report to help you understand the performance of your apps and messaging campaigns.

## Subscribing to reports

You can subscribe to this report on from the Notification Preferences page.

- Go to Settings > Admin Settings > Notification Preferences.
 
- Select the Weekly Analytics Report and add yourself or other Braze dashboard users to the list recipients. External email addresses can’t be added.

## Adding custom events to reports

Additionally, if you’re using custom events, you can select up to five key events from the Custom Events page to be included in your weekly report. Go to Data Settings > Custom Events to update these events at any time.
