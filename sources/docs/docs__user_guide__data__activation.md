# Data activation 

After unifying your data in Braze, it’s time to use it. This involves understanding your customers’ behaviors and preferences in real-time with user profiles and segments. Then, activate your data by creating targeted messages, personalizing experiences, and setting up customer journeys that respond to what your customers do in real time. 

Data activation in Braze is powered by your custom data. For more details, refer to Custom data.
