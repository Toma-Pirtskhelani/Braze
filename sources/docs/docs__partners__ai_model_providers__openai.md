# OpenAI

OpenAI creates advanced AI models, like GPT, that enable natural language understanding and generation, empowering brands to build and scale meaningful customer interactions.

important

This partner appears on your Technology Partners page only if you have Braze Agents enabled. For help getting started, contact your customer success manager.

This integration is maintained by OpenAI.

## About the integration

The Braze and OpenAI integration lets you connect your OpenAI API key to Braze so you can use OpenAI models when building custom AI agents. With this integration, your agents can generate personalized copy, make real-time decisions, or update catalog fields using OpenAI’s large language models.

## Prerequisites

 Requirements | 
 Description | 

 OpenAI account with API key |

 Braze instance |

## Integration

To connect your OpenAI API key to Braze:

- Go to Partner Integrations > Technology Partners in the Braze dashboard and find OpenAI.
 
- Enter your API key from OpenAI.
 
- Select Save.

After saving, you can select OpenAI models when creating a custom agent in the Agent Console.

Contact OpenAI support with any issues or questions regarding your integration.
