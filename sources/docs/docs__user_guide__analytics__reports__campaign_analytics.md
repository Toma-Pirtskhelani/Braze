# Campaign analytics 

Campaign analytics gives you real-time updates on high-level results of each campaign and variant within that campaign, as well as message-level details. Choose your messaging channel from those listed to learn more about campaign analytics specific to that channel. You can also check out the Campaign Setup Braze Learning course for an overview of these analytics.
