# Administer 

Set up and manage your Braze dashboard, including workspaces, user permissions, security, and billing. Personal settings cover your individual account access and preferences, while global settings affect your entire company or workspace.

In addition to the topics and articles included in this section, check out the Admin and Dashboard Management Braze Learning course, which covers how to manage user access and best practices for dashboard maintenance.
